La veille

  1. Double-cliquer techauto-dms\demarrer.bat, laisser la fenêtre ouverte
  2. Ouvrir localhost:8080 : la journée type est-elle là ?
    Sinon : Paramètres → 📅 Charger une journée type
  3. Téléphone sur le même Wi-Fi → 192.168.1.24:8080/mecano → Mécano 1, code 0000
  4. Ouvrir presentation-pdg.html dans le navigateur
  5. Ouvrir le site techauto-one.vercel.app dans un onglet

Repartir de zéro (si besoin)

  1. Fermer la fenêtre du serveur
  2. Dans techauto-dms\data, supprimer tout sauf config.json
  3. Relancer demarrer.bat
  4. Paramètres → 📅 Charger une journée type

  2. Identifiant « TECH'AUTO DMS – clé API » : Header Auth, nom X-API-Key, valeur = ligne apiKey de data\config.json
  3. Identifiant « Brevo – clé API » : nom api-key (pour les SMS)
  4. Nœud « Choisir le SMS » : NUMERO_CHEF, NUMERO_ACCUEIL
  5. Tailscale sur le serveur Hostinger (même compte que ce PC)
  6. Activer le workflow
  7. DMS → Paramètres → Webhook n8n :
